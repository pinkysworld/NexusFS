# Glossary

- **CAS**: Content-Addressed Store (hash → blob).
- **Oplog**: Append-only operation log (signed).
- **Head**: Current snapshot hash (commit of state).
- **CRDT**: Conflict-free Replicated Data Type (mergeable state).
- **Transparent proof**: Non-ZK structured evidence (hashes, signatures).
- **ZkCommit**: ZK proofs over SNARK-friendly commitments and roots.
- **TOFU**: Trust On First Use.
