Roadmap

Every milestone stays runnable.

NexusFS is staged as a vertical-slice project so the repository remains a usable system at each step, not a pile of disconnected prototypes.

Near-term implementation focus

  • Finish full CRDT-backed local apply in the core state machine.
  • Expose richer local state through the admin surface.
  • Bring up end-to-end oplog and blob replication between nodes.
  • Add encrypted chunk storage and transparent proof verification.

A staged path from practical storage to deeper proof systems.
